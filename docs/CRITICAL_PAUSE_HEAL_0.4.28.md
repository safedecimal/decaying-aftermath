# Критические эффекты, запрет паузы и /heal — 0.4.28

ChatScreen/меню больше не исключают медицинский foreground: красная маска боли,
затемнение, виньетка и круг остаются в финальном GUI-проходе. Интерфейс настоящей
смерти/возрождения не блокируется.

При UNCONSCIOUS, DYING, Last Standing, остановке сердца или опасных показателях
крови/кислорода/мозга/боли Esc не открывает паузу. Также заблокирован прямой вызов
pauseGame, автоматическая пауза при потере фокуса и другие pausing screens.
Если критическое состояние пришло при уже открытой паузе, Gui закрывает её.
Клиент не сообщает isPaused=true; серверное время продолжает идти.
Сверху показывается текст «Сейчас не время останавливаться. Держись.» с прозрачностью
0.65 и плавным исчезновением. Чат остаётся доступен для команд. После восстановления
меню паузы снова работает. Закрытие приложения/ОС не блокируется.

`/heal` — серверная команда для оператора с уровнем 2+ (GAMEMASTERS), только для себя.
Проверка права есть и в command tree, и в executor на случай пересечения с чужой
командой. Console без player entity не имеет «себя»; после фактической смерти нужно
возродиться, команда не оживляет Minecraft death entity.

Команда создаёт чистый BodyModel: полные кровь, кислород, энергия, мозг, вода/питание;
нет травм, кровотечения, инфекции, переломов, ожогов, ядов, радиации, препаратов,
лечебных таймеров или аварийного ритма. Снимаются vanilla status effects, огонь,
замерзание; восстанавливаются дыхание, HP до фактического максимума и голод.
Убираются medical modifiers и live medical ragdoll, прерываются процедуры и
дефибрилляторные сессии. Новый снимок сразу синхронизируется, клиент очищает медицинскую
презентацию. Инвентарь, группа крови, позиция и прочие игроки не меняются.
Опасная окружающая среда может снова причинить повреждение после команды.

Проверяются реальные Esc/ChatScreen/PauseScreen, ход времени интегрированного сервера,
запрет /heal для permission0, полноценный self-heal для OP2, синхронизация клиента
и доступность здоровой паузы после восстановления. Тест создаёт отдельный мир проекта.
