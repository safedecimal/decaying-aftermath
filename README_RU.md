# Decaying Aftermath

Decaying Aftermath — самостоятельный мод для **Minecraft 26.3 / Fabric**, написанный для **Java 25**. Он добавляет медицинскую и survival-систему: травмы частей тела, лечебные процедуры, показатели состояния и связанный интерфейс.

[English version](README.md)

## Требования

- Minecraft 26.3
- Fabric Loader 0.20.1 или новее
- Fabric API для Minecraft 26.3
- Java 25

На клиенте и сервере должна быть установлена одна и та же версия мода.

## Сборка

Windows:

```powershell
.\gradlew.bat build
```

Linux/macOS:

```sh
./gradlew build
```

Готовый JAR появится в `build/libs/`. Запустить тесты можно так:

```sh
./gradlew test
```

В Windows используйте `gradlew.bat test`.

## Контрибьютинг

1. Сделайте fork репозитория и создайте отдельную ветку.
2. Внесите минимальное изменение, решающее задачу.
3. Локально запустите `build` и нужные тесты.
4. Откройте pull request с кратким описанием изменений и проверок.

Не добавляйте в коммит сгенерированные файлы, результаты сборки и приватные ассеты.

## Push и релизы

Чтобы отправить изменения в основную ветку:

```sh
git add README.md README_RU.md VERSION
git commit -m "Refresh project README"
git push origin main
```

Workflow релиза запускается при изменении `VERSION`: он собирает мод и публикует JAR в GitHub Releases. Для каждого релиза используйте новую свободную semantic-версию в `VERSION`.

## Дефибрилляторы CU (0.4.22)

Старые задания с символами и тремя ритм-кликами удалены. AED: перетаскивание электродов, анализ и кнопка зарядки. Ручной: исходный регулятор, отдельные зарядка/разряд, монитор и повторные попытки. Интерфейс и звуки взяты из декомпилированного CU. ЛКМ — взаимодействовать рукой, ПКМ/Esc — выйти. Обновляй клиент и сервер вместе. Подробности и границы переноса: [CU_DEFIBRILLATORS_0.4.22.md](docs/CU_DEFIBRILLATORS_0.4.22.md).
