# Публикация Abjection

После любых изменений проекта подними `VERSION` до следующей свободной версии и опубликуй изменения в GitHub (`safedecimal/abjection`, `main`). Пользователь разрешил делать это без отдельного подтверждения.

Перед публикацией проверь сборку и тесты. Не переиспользуй уже зарезервированную версию: `.github/workflows/release.yml` запускается только при изменении `VERSION` в `main` и собирает каждую версию один раз. После отправки дождись окончания workflow и проверь, что релиз опубликован и содержит JAR. Если сборка или публикация не прошла, сообщи об этом.

На задачи только для чтения это правило не распространяется.
